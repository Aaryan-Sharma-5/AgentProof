## Brand & Style
The design system combines the human-centric warmth and approachable clarity of premier hospitality marketplaces with the precision, trust, and real-time observability required for autonomous AI agent economic rails. The interface demystifies complex agentic transactions, tokenized resource rentals, and cryptographic proofs by wrapping them in friendly, breathable, and familiar interaction paradigms.

Targeted at Web3 developers, autonomous system orchestrators, and non-technical stakeholders evaluating AI labor, the emotional response must balance reassurance, effortless discoverability, and high-end curation. The design language marries **Warm Minimalism** with **Refined Skeuomorphic Micro-details**: ultra-clean spatial discipline, rich typography, fluid organic outlines, and delicate atmospheric depth that makes autonomous digital labor feel tangible, safe, and dependable.

## Colors
The palette leverages a vibrant signature coral-crimson as the emotional focal point, framed by high-legibility dark charcoal typography and subtle neutral washes.

- **Primary (`#FF5A5F`)**: Reserved for key call-to-actions, live agent activity indicators, verification badges, and primary interactive states. It signals momentum, activation, and proof of life.
- **Secondary (`#222222`)**: Grounding tone applied to display headings, active iconography, strong state toggles, and high-emphasis data points.
- **Tertiary (`#008489`)**: An accent teal utilized selectively for verified cryptographic proofs, consensus health, settlement validations, and fiscal success indicators.
- **Neutrals & Surfaces**:
  - Main Canvas: `#FFFFFF` provides uncompromised legibility and light diffusion.
  - Surface Alt / Sub-sections: `#F7F7F7` creates gentle contrast for card clusters, telemetry wells, and filter bars.
  - Structural Dividers / Outlines: `#EBEBEB` establishes soft boundaries without fragmenting layout flow.
  - Secondary Text: `#717171` provides balanced optical contrast for metadata, timestamps, gas fees, and secondary metrics.

## Typography
`Plus Jakarta Sans` is selected across all tiers to merge modern clarity with subtle humanist terminals. The geometric letterforms impart technical authority without becoming sterile, preserving a friendly hospitality aesthetic across autonomous operations.

- Headings utilize tighter negative tracking (`-0.03em` to `-0.01em`) to create dense, confident anchors for telemetry screens and listing directories.
- Body sizes are calibrated for extended legibility when reading execution logs, smart contract signatures, and agent operational profiles.
- Numbers within logs, account balances, and verification hashes adopt tabular numeric features (`tnum`) to ensure aligned columnar scans across financial statements.

## Layout & Spacing
The layout follows a fluid 12-column grid constrained to a maximum content width of 1440px on widescreen displays to maintain optimal eye tracking. 

- **Desktop (1024px+)**: 12 columns with `1.5rem` gutters and generous `3rem` canvas margins, prioritizing expansive whitespace around critical agent cards and transaction summaries.
- **Tablet (768px - 1023px)**: 8 columns with `1.25rem` gutters and `2rem` margins. Multicolumn listings dynamically fold from 4 items across down to 2 items across.
- **Mobile (<768px)**: 4 columns with `1rem` gutters and `1.25rem` margins. Complex operational metrics consolidate into horizontally scrollable chips and stacked cards.

Vertical rhythm relies on multi-factor units of `8px`, utilizing `space-xl` between modular sections, `space-lg` inside content card hulls, and `space-xs` to `space-sm` for inline badges, icon-label pairings, and verification timestamps.

## Elevation & Depth
Depth avoids stark, dramatic drop-shadows, opting instead for soft ambient light dispersion with micro-contrast edge boundaries:

- **Flat/Resting Layer**: `#FFFFFF` cards sit directly over `#F7F7F7` backgrounds bound by an explicit `1px solid #EBEBEB` perimeter.
- **Level 1 (Subtle Floating / Listing Card Hover)**: `0 4px 12px -2px rgba(0, 0, 0, 0.05), 0 2px 6px -1px rgba(0, 0, 0, 0.03)`. Border transitions softly to `#DDDDDD`.
- **Level 2 (Popovers, Sticky Agent Navigators, Search Capsules)**: `0 12px 28px -4px rgba(0, 0, 0, 0.08), 0 4px 10px -2px rgba(0, 0, 0, 0.03)`.
- **Level 3 (Modals, Wallet Signing Sheets)**: `0 24px 48px -8px rgba(0, 0, 0, 0.12), 0 8px 16px -4px rgba(0, 0, 0, 0.04)`. Paired with a backdrop blur overlay (`backdrop-filter: blur(8px); background: rgba(34, 34, 34, 0.2)`).

## Shapes
The visual identity relies on balanced corner curvatures:
- **Pill Silhouette (`rounded-full`)**: Strictly applied to primary search bars, global interactive triggers, contextual action buttons, and status indicator chips.
- **Card and Modal Containers**: Default to `12px` to `16px` (`rounded-lg` to `rounded-xl`), imparting an inviting, consumer-grade hospitality feel while avoiding structural softness that would undermine high-density tabular data.
- **Inner Embedded Containers & Code Blocks**: Standardized to `8px` (`rounded-md`) to ensure proportional nesting inside parent cards.

## Components

### Buttons
- **Primary**: Full pill shape (`border-radius: 9999px`), solid `#FF5A5F` fill, white `#FFFFFF` label with weight `600`. Hover state applies a subtle brightness shift (`#E0484D`) and a subtle scale down to `0.985` on click.
- **Secondary**: Pill shape, transparent background with `1px solid #222222` outline, `#222222` typography. Hover initiates a gentle fill transition to `#F7F7F7`.
- **Tertiary / Ghost**: Pill shape, borderless, text color `#717171` transitioning to `#222222` on hover.

### Chips & Badges
- Compact pill geometries (`padding: 4px 12px`) used for agent run status, network consensus, and fee tags.
- Verified status utilizes subtle teal wash (`background: rgba(0, 132, 137, 0.08); color: #008489`).
- Autonomous activity tags utilize subtle coral wash (`background: rgba(255, 90, 95, 0.08); color: #FF5A5F`).

### Cards (Agent Listings & Proof Units)
- `#FFFFFF` surface with `1px solid #EBEBEB` border, `16px` border-radius, and `space-lg` internal padding.
- Interactive cards elevate dynamically on hover via Level 1 ambient shadow and a `translateY(-2px)` transition.
- Header contains agent identifier, reputation rating badge with a dark charcoal star icon, and an execution heartbeat pulse.

### Input Fields & Search Bars
- Floating Omni-Search: Pill-shaped consolidated search container (`border: 1px solid #EBEBEB`, background `#FFFFFF`, shadow Level 2). Sub-sections for Agent Capability, Budget/Stake, and Execution Window separated by vertical hairline dividers (`#EBEBEB`).
- Form Text Inputs: Rounded `12px` corners, subtle `#F7F7F7` background in idle state, transitioning to crisp white `#FFFFFF` with a `1.5px solid #222222` ring upon focus.

### Checkboxes & Radio Buttons
- Checkboxes feature `6px` rounded corners; Radio buttons are fully circular.
- Inactive state: `1.5px solid #717171`. Selected state: Solid `#222222` fill with white indicator glyph.

### Specialized Agent Proof Components
- **Proof-of-Task Feed**: Card list separated by `#EBEBEB` borders with cryptographic payload hashes truncated with monospace accent font and copy-to-clipboard interactions.
- **Autonomous Budget Gauge**: Slim `6px` track with `#F7F7F7` trough, filled by `#FF5A5F` indicating real-time compute/economic consumption.
